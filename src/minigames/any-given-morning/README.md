# Any Given Morning

Motivator: Meaning. Author: NICOH-YAY.

## Mechanic

An ordinary morning with people who need a little help. Run `npm run dev` and open the Meaning page. M1 has a menu placeholder. Start has no effect yet. The rules run in headless tests.

Planned controls use WASD or arrows to move. E, Space or Enter interacts with the nearest person or object. Touch controls will have a d-pad and an A button. Esc returns to the menu.

Mortality starts on. Each life ends after 16 to 24 seconds, whatever you do. Five lives make a round. With Mortality off, one life lasts 100 seconds. You can help someone or stay where you are. Deeds appear after a life ends. Up to six traces of earlier deeds appear in later areas. There is no timer on screen.

The round ledger will ask what you felt and whether the switch changed what you did. Nobody has playtested M1.
